# Notes App

A full-stack notes application built with the MERN stack.

## Features

* Create Note
* Read Note
* Update Note
* Delete Note

## Tech Stack

* MongoDB
* Express.js
* React.js
* Node.js

## Frontend Packages

* Tailwind CSS
* Axios
* React Router DOM
* Lucide React
* React Hot Toast
* Vite

## Backend Packages

* Express
* Mongoose
* bcrypt
* JSON Web Token (JWT)
* dotenv
* cors

## Installation

Install dependencies for both the frontend and backend:

```bash
cd frontend
npm install

cd ../backend
npm install
```
